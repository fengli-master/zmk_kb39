# 中国大陆采购与加工指南

[English version](china-sourcing.md)

以下是面向中国大陆制作者的建议原型路线。在轨迹球支架 STL 已完成打样
并在本仓库标记为可用之前，不要下单生产最终支架。

## 1. 通过嘉立创/JLCPCB 制作键盘 PCB

从上游 `keyball39/design_data` 目录直接下载以下四个生产压缩包：

- `Keyball39_BallSide_MiddlePCB.zip`
- `Keyball39_BallSide_TopPCB.zip`
- `Keyball39_NoBallSide_MiddlePCB.zip`
- `Keyball39_NoBallSide_TopPCB.zip`

来源：<https://github.com/Yowkees/keyball/tree/main/keyball39/design_data>

将每个 ZIP 分别作为一个双层 PCB 订单上传。不要合并四个 ZIP，也不要把
KiCad 源文件压缩包当作生产文件上传。除非 Gerber 预览或工程审核发现
问题，初始参数使用：

- FR-4，双层铜；
- 板厚 1.6 mm；
- 铜厚 1 oz；
- 黑色阻焊；
- 白色丝印；
- 无铅喷锡或沉金表面处理；
- 不选择 PCBA 贴片服务。

在在线 Gerber 查看器中检查全部四个订单。付款前确认板框、内部开槽、
非金属化孔和尺寸。如平台提供“生产稿确认”，建议勾选。工厂会按 Gerber
生产，不会根据旁边附带的 PDF 或备注自行推断要求。

顶层 PCB 是结构定位板，中层 PCB 才包含电路。常规打样的最低数量通常
大于一片，因此会有备用板。

## 2. 通过淘宝激光切割亚克力

使用以下两个上游文件：

- `Keyball39_MiddleAcryl_3mm_98x187mm.dxf`
- `Keyball39_BottomAcryl_2mm_136x185mm.dxf`

淘宝搜索词：

- `亚克力 激光切割 DXF 来图定制`
- `黑色磨砂亚克力板 激光切割`

发给商家的说明：

> DXF 按毫米单位 1:1 切割，不缩放；中间层 3mm，底板 2mm。请保留全部孔位和内部轮廓，先发排版图确认。

生产前要求商家发送排版图确认。板材厚度属于机械堆叠尺寸；除非同时修改
铜柱长度，否则不要更改厚度。

## 3. 电子与机械零件

下表提供淘宝/1688 搜索词。不要只根据商品标题下单，应核对详情页中的
尺寸和引脚定义。

| 零件 | 搜索词 | 验收要求 |
| --- | --- | --- |
| 控制器 | `nice nano v2 nRF52840 ProMicro ZMK` | Pro Micro 尺寸、UF2 引导程序、电池焊盘 |
| 控制器插座 | `圆孔排母 2.54 低矮 12P` | 针径匹配，并为电池留出足够空间 |
| 插座针脚 | `康斯特针 2.54 键盘 nice nano` | 与所选圆孔排母匹配 |
| 电池 | `301230 3.7V 100mAh 带保护 锂聚合物` | 有保护板，尺寸与标注极性正确 |
| 电源开关 | `贴片拨动开关 SPST 键盘` | 安装后能够操作，并且是自锁型 |
| OLED | `0.91寸 OLED 12832 SSD1306 I2C 4针 3.3V` | 地址 0x3C，VCC/GND/SCL/SDA 顺序正确 |
| PMW3610 模块 | `PMW3610 成品模块 已焊接 已测试 LM18-LSI 3.3V ZMK` | 已安装传感器和镜头；引出 VIN/GND/SCLK/SDIO/nCS/MOTION；卖家提供针脚图和尺寸 |
| 轨迹球 | `34mm 轨迹球 球体` | 实际直径 34 mm，表面有可识别图案 |
| 支撑球 | `2mm 氧化锆 陶瓷球` | 等级与直径一致，多购买几个备用 |
| MX 轴座 | `凯华 MX 热插拔轴座` | Kailh 型 PCB 热插拔封装 |
| 二极管 | `1N4148W SOD-123` | SOD-123 封装，阴极标记清晰 |
| 轴体 | `MX 机械键盘轴 5脚` | 39 个相同轴体，另加备用 |
| 键帽 | `1U 等高 MX 键帽 39键` | MX 十字轴心，建议使用统一高度 |
| 紧固件 | `M2 铜柱 7mm 9mm M2螺丝` | 双通铜柱及匹配的短螺丝 |

第一次制作建议使用正品 nice!nano v2。如果使用兼容板，连接锂电池前必须
确认电池焊盘极性、充电电路、引导程序、GPIO 映射和元件高度。

不要购买标为 `裸板`、`散件`、`传感器+镜头` 或 `需自行焊接` 的商品。
要求卖家确认 PMW3610 和 LM18-LSI 均已安装，并且模块已在 3.3 V 下通过
移动输出测试。索取 PCB 正反面清晰照片、针脚图、PCB 外形尺寸、安装孔
位置以及镜头到 PCB 的高度。

优先选择组装完成的紧凑型 ufan 模块。其他全成品模块在电气接口核对通过
后也可以使用。确定具体模块前不要订购打印的传感器支架，因为模块外形、
安装孔和镜头高度都会决定支架结构。

## 4. 通过嘉立创 3D 打印制作轨迹球支架

完成后的支架会以 STL 文件提供。第一次尺寸验证先订购一个 SLA 树脂件。
卡扣、支撑球孔和螺丝结构周围的设计壁厚至少为 1.5 mm。收到后测量成品，
并测试球体滚动与传感器追踪，再考虑其他材料。

尺寸验证完成后，最终件建议使用更坚韧的 MJF PA12 尼龙，但它的尺寸公差
比 SLA 更大。因此支撑球孔和传感器高度必须预留合理间隙，不能依赖过盈
压配。

建议订单备注：

> 关键装配件，请勿自动缩放。孔位和传感器高度为功能尺寸；支撑请尽量放在非配合面，后处理不要打磨轴承孔和传感器定位面。

如果平台报告模型几何错误，不要选择自动修复。应先修改源模型，防止功能
尺寸被系统悄悄改变。

## 5. 工具

最低限度建议准备：

- 带温控、配小型刀头的电烙铁；
- 0.5～0.8 mm 电子焊锡丝和助焊剂；
- 精细镊子和水口钳；
- 带通断档的数字万用表；
- USB-C 数据线；
- Kapton 胶带或其他电气绝缘材料；
- 护目镜；
- 小号十字螺丝刀和 M2 紧固件工具。

此无线版本不要购买 PMW3360 传感器板或 ATmega32U4 Pro Micro 控制器，
也不要安装原版 TRRS 插座或 RGB LED。
